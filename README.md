# Juego Arcade en C++ – "Battle Console"

Este es un juego estilo arcade en consola hecho en C++, que simula dos niveles de combate con disparos, enemigos, puntajes y animaciones simples. Está diseñado completamente con librerías nativas como `windows.h` y `conio.h`, y usa una librería creada llamada `spritezi.h` para efectos visuales.

---

## Características

- Dos niveles con dificultad progresiva
- Sistema de disparo, enemigos y colisiones
- Puntuación según desempeño
-  Menú inicial con instrucciones, créditos y salida
- Animaciones tipo "spritezi" para efectos visuales
- Completamente jugable en la consola de Windows

---

## Cómo ejecutar el juego

1. Asegúrate de estar en **Windows**.
2. Compílalo con un entorno como Dev C++, Code::Blocks o Visual Studio.
3. Asegúrate de tener los archivos:
   - `main.cpp`
   - `spritezi.h`
   - `animacion1`

---

## Instrucciones del juego

- Usa las teclas de dirección para moverte.
- Dispara con la tecla `W`.
- Derrota a todos los enemigos para avanzar de nivel.
- Al final recibirás una puntuación y una calificación.

---

## Calificaciones

- **S**: Excelente desempeño.
- **A/B/C**: Bueno a regular.
- **F**: Derrotado o puntaje bajo.
